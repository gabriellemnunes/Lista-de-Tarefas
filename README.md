# Lista de Tarefas

Projeto de uma lista de tarefas simples e responsiva, desenvolvido como
atividade acadêmica utilizando HTML, CSS e JavaScript.

## Funcionalidades

- Adicionar novas tarefas;
- Marcar tarefas como concluídas;
- Desfazer uma tarefa concluída;
- Excluir tarefas;
- Adaptar a página para computadores e celulares.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript.

## Como usar

Digite uma tarefa no campo indicado e clique em **Adicionar**. Depois, utilize
os botões **Concluir** ou **Excluir** para organizar a lista.
