# Minha Lista de Tarefas

Projeto simples e responsivo desenvolvido para a Atividade Individual 01.

## Funcionalidades

- Adicionar tarefas
- Marcar tarefas como concluídas
- Desfazer a conclusão
- Excluir tarefas
- Layout adaptado para computador e celular

## Tecnologias

- HTML
- CSS
- JavaScript

## Como executar

Abra o arquivo `index.html` no navegador.

## Publicação no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie estes quatro arquivos para a raiz do repositório.
3. No repositório, acesse **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main`, a pasta `/ (root)` e clique em **Save**.
6. Aguarde o GitHub mostrar o endereço público da página.
